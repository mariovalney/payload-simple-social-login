# Agents

## Payload

This project uses the Payload CMS skill at `.agents/skills/payload/`.
Start with `.agents/skills/payload/SKILL.md` for a quick reference, then see `.agents/skills/payload/reference/` for detailed docs.

When in doubt about Payload APIs, plugins, auth, endpoints, or config patterns, treat `.agents/skills/payload/` as the source of truth, then [Payload docs](https://payloadcms.com/docs/plugins/build-your-own).

## Commits

For a standardized commit, use the **commit** skill at `.agents/skills/commit/SKILL.md` (invoke with `/commit`).
